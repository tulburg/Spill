## Purpose
Some questions need several picks. This is the only part of S-3 that S-20 (answer from the card) and S-21 (approval gate) did not already ship. Per D-6.

## Requirements
1. `spill_ask` takes `multi: true` for multi select; single select stays the default. The card file records it.
2. A multi select question shows checkboxes instead of option buttons, on the card and in the side sheet.
3. The answer button reads "Answer A, C" and is disabled until at least one option is picked. Other is free text and can be added to picks.
4. A multi select answer records one `D-n` whose title lists every pick ("A, C. title A; title C").
5. `spill answer Q-n A,C` answers a multi select question from the CLI.
6. A spec with open questions shows a count badge ("2 questions") in its header, in the amber accent; it drops as questions are answered.

## Out of scope
- Changes to single select answering (S-20).
- The search dropdown count (belongs to S-7).

## Acceptance checks
- `spill_ask` without `multi`: option buttons, one pick, as today.
- `spill_ask` with `multi: true`: checkboxes; picking A and C records one decision listing both.
- Answer button disabled with nothing picked.
- `spill answer Q-n A,C` records the same decision as the app.
- Badge shows the open count and drops after an answer.
