## Purpose
A failing check is one click away from being fixed. No typing, no extra panel.

## Requirements
1. Each failing check in the side sheet's Checks box gets a tiny "Fix" button at the end of its line (text button, 11px, same height as the line).
2. The card's check row ("4 of 5 checks", red) gets the same tiny "Fix" button on the right, in place of the time. With several failures it fixes all of them.
3. Clicking adds a user comment on the spec, "Fix failing check: <name>" (one line per check), so it reaches Claude through `spill_inbox`. No new tool.
4. After clicking, the button reads "Sent" and is disabled until the next checks run for that spec.
5. On that comment Claude sets the spec `active`, fixes it, runs the checks again with `spill_checks`, and moves it back to `done`. SPILL.md says so.

## Out of scope
- Fix for passing or running checks.
- Claude fixing without the click.

## Acceptance checks
- A spec with a failing check shows Fix in the sheet line and on the card row.
- Clicking Fix adds the comment and `spill_inbox` shows it.
- The button reads Sent until a new checks run lands, then disappears if all pass.
