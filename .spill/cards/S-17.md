## Purpose
A desktop window that shows the real board from `.spill/`, built to the approved specs, so every approved spec is visible and checkable in the app itself.

## Requirements
1. `spill app` starts a local bun server for the project and opens a Tauri window on it. `spill serve` starts only the server, for a browser.
2. The server reads cards through the same store as the MCP server, and pushes a live update to the window whenever anything in `.spill/` changes (Claude, the CLI, or a hand edit).
3. Hierarchy for the columns (S-9): a question's parent is the first spec it blocks; a decision's parent is the question it answers; a spec's parent is the first spec it depends on. Cards with no parent are top level.
4. Built from the approved specs: hierarchy columns with colored lines (S-9), section headers (S-11), decision strip (S-12), check rows (S-13), blocked marker (S-14), branch cards (S-15).
5. Approve and Reject on specs that are draft or discussing, acting as the user. These go through the store and appear in Claude's spill_inbox.
6. No new JavaScript dependencies; the UI is plain TypeScript bundled by bun. Rust crates: tauri and tauri-build only.

## Out of scope
- Draft specs not yet approved (toolbar, composer, question popup, preview, notifications). They appear on the canvas as cards but their features are not built.

## Acceptance checks
- `spill app` opens a window showing every card in `.spill/cards`.
- Approving a spec in the window changes its card file, its look, and the next spill_inbox.
- A change made with the CLI shows in the open window within a second.
