Spec versions are recorded today only when the spec text changes. Designs usually change many times between text edits (each draw call is a change), so if snapshots happen only on text edits, the approved version can show designs older than what you actually approved. S-47 req 4 needs the approved state kept.

- A. On text edits and at approval: a version is also recorded at approval when the designs changed since the last version, so the approved version holds exactly what you approved (recommended)
- B. On text edits only: designs are copied only when the spec text changes
- C. On every design change: each edit by Claude records a version (many versions)
