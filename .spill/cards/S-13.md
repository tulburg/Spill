## Purpose
A failing acceptance check should be visible on the canvas without opening the spec.

## Requirements
1. Every spec card with acceptance checks shows a check row: a dot and "n of m checks", plus the time of the last run.
2. Dot colors: green when all pass, red when any fail, grey when not run yet, pulsing green while running.
3. A failing check names the first failing script on the card ("weights_sum.py failed").
4. Clicking the check row opens the preview scrolled to Acceptance checks.
5. The "Needs you" filter in search (S-7) includes specs with failing checks.

## Out of scope
- Running checks from the card. Claude runs them; the card only reports.

## Acceptance checks
- A spec with one failing check shows a red dot and the script name on the canvas.
