## Purpose
The user should see at a glance which cards Claude is talking about right now and which come next, without reading chat. Claude sets this focus through the MCP server.

## Requirements
1. A new MCP tool `spill_focus` sets the spotlight: `discussing` (card IDs being talked about now), `next` (card IDs up next, in order), and an optional one-line `note`. Calling it with `clear: true` removes the spotlight.
2. Unknown card IDs are refused. The focus is stored in `.spill/focus.json` and every change is logged in `events.jsonl` as a `focus` event by Claude.
3. `spill_board` lists the current focus at the top so Claude sees it at the start of a session.
4. The app shows the spotlight in the bottom-left panel, above Recent decisions: a "Discussing" group (cards and the note) and an "Up next" group (numbered cards). Clicking a card there pans to it, opening its section if collapsed.
5. Discussing cards get a strong indigo ring and an "In discussion" tag; next cards get a dashed ring and their place in line ("Next 1", "Next 2"). Other cards dim until the user hides the spotlight.
6. When the focus changes, the app pans to the first discussing card once. The user can hide the spotlight from the panel header (Hide/Show); it comes back on the next focus change.
7. `spill focus` on the CLI prints the current focus.

## Out of scope
- The user setting focus from the app.
- History of past focus beyond the event log.

## Acceptance checks
- Calling `spill_focus` with discussing S-11 and next S-16, S-17 updates the open app within a second: the bottom-left panel lists them, S-11 ringed, others dimmed.
- `spill_focus` with an unknown ID returns an error and changes nothing.
- `clear: true` removes the bar and the rings.
