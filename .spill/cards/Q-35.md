Spill's desktop UI is a TypeScript web page in a Tauri window.

- A. Native SwiftUI app (best feel and notification handling; a second UI to maintain)
- B. Tauri 2 mobile, reusing a phone layout of the existing web UI (one codebase; less native feel)
- C. A thin SwiftUI shell around a phone layout of the web UI in a web view, with native notifications
