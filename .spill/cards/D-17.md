A change request on a done spec is handled by Claude on the same spec where it can be: the spec becomes active again, Claude can ask questions on it, or Claude updates the spec, which then waits for approval again. When a spec is updated, the board shows what changed (versions of the spec with a diff view). Only when the change is too big does Claude branch a new spec, or delete the spec and replace it with a brand new one. Deleting a spec means deleting all the implementation and code built for it.
