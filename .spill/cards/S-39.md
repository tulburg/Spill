## Purpose
Spill has no settings. A Settings panel in the style of a macOS preferences window gives the theme a home, and a place for project details.

## Requirements
1. Settings opens from Spill > Settings... (Cmd+,) in the app menu and from the project menu in the top bar. It is a panel over the board, styled with Spill components: a segmented tab bar at the top, grouped rows below, and Esc or the close button to dismiss.
2. Two tabs: General and Appearance.
3. General shows details, read only for now: project name, project folder (with a button to reveal it in Finder in the app), the board folder and its card counts by kind, whether Claude's MCP server has connected recently (from the last Claude event), and Spill's version.
4. Appearance has Theme: System, Light, Dark, as a three-way segmented control. Picking one applies it at once (S-38 tokens).
5. The theme choice is saved under ~/.spill/settings.json through the board server, so every project window shares it; other open windows pick up the change within a few seconds.
6. The Settings panel itself follows the current theme.

## Out of scope
- Editable general settings (launch at login, menu bar icon and so on).
- Per-project themes.

## Acceptance checks
1. Cmd+, and the project menu item both open Settings on the General tab; Esc closes it.
2. General shows the correct project name, folder, card counts and version.
3. Choosing Dark, Light and System in Appearance switches the board at once; System follows the OS.
4. The choice survives a reload and reaches a second project window.
