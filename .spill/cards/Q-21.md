S-36 needs the menus to know about every open project window. Today each project runs its own Spill process with its own window, so no process knows about the others. My pick is A: the Window menu and "bring forward" are what macOS gives one app for free; B needs a shared file plus a way to raise another process's window, which is fragile.
- A. One Spill app process holds every project window; each window still talks to its own project's board server, which the app starts and stops. Running `spill app` in a folder while Spill is open adds a window to the running app.
- B. Keep one process per project; they share a list of open windows in a file under the home folder and ask each other to come forward.
