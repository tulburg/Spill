## Purpose
Spill opens one window per project, but you can only open another project from a terminal, and nothing lists the windows already open. The menu bar should do both. Opening Spill again (from the Dock or Finder) resumes where you left off, with the project windows that were open when it quit.

## Requirements
1. Spill remembers every project it opens (folder, project name, last opened) in a list under the user's home folder, most recent first.
2. The File menu has "Open Recent" listing those projects, up to 10, with "Clear Menu" at the bottom. Picking one opens that project's board in a new window, or brings its window forward if it is already open.
3. The File menu has "Open Project..." with a folder picker. Picking a folder that has a .spill folder (in it or above it) opens its board in a new window; a folder without one shows an error saying so.
4. A project opened from the menu gets a free port on its own; no port is typed.
5. The Window menu lists every open Spill window by project name, marks the current one, and picking one brings it forward.
6. Closing a window stops its board server, as today, and removes it from the Window menu.
7. How the windows are hosted (one app process or one per project) follows Q-21.
8. When Spill quits (Quit, Cmd+Q, or logging out), it saves the list of project windows that were open, in order, under the user's home folder. Closing the last window by hand leaves an empty list, so the next launch does not reopen it.
9. Launched without a project (from the Dock, Finder or Spotlight), Spill reopens every saved project window, each on a free port, and focuses the one that was in front. Projects whose folder or .spill board no longer exists are skipped, with no error.
10. With nothing saved and nothing to open, Spill opens the most recent project from Open Recent; with no recent projects either, it shows "Open a Spill project" with the folder picker instead of an error about the current folder.
11. Launched with a project (`spill app` in a folder), Spill opens that project and also restores the saved windows, without a second window for the same project.

## Out of scope
- Creating a new .spill board from the menu.
- The in-app "Switch project" item in the project menu.
- Restoring window positions, sizes, open sheets or design windows.

## Acceptance checks
1. After opening two projects, File > Open Recent lists both, newest first.
2. Picking a recent project that is not open opens it in a new window on a free port; picking one that is open brings its window forward.
3. Open Project... on a folder without .spill shows an error and opens nothing.
4. With two windows open, the Window menu lists both by name and switches between them.
5. Closing a window removes it from the Window menu and stops its server.
6. With two projects open, Quit and open Spill from the Dock: both windows come back.
7. Close every window, quit, and open from the Dock: the most recent project opens (not an error).
8. A saved project whose folder was deleted is skipped on launch.
