## Purpose
The user can talk to Claude about anything, not tied to a card, without adding a new element to the screen (D-3, Paper board 13 option A).

## Requirements
1. A message button sits at the right end of the top bar, the same size as the S logo on the left. Tooltip: "Message Claude (/)".
2. Clicking it, or pressing `/` when no input has focus, converts the top bar in place into a message input: the logo stays, the rest becomes the input with an Enter hint. Esc or clicking away with an empty input turns it back.
3. Enter sends: the message is logged as a board-level user event (`message`, no card) and the bar turns back. It appears in Claude's `spill_inbox` and wakes Claude like any approval. Typed text survives live redraws.
4. New MCP tool `spill_reply` (text): Claude answers a board-level message. It is logged as a Claude `reply` event.
5. A new reply drops under the top bar as a small card ("Claude: ...") for 8 seconds, and the top bar reads "Claude replied" meanwhile. While unseen, the message button shows a dot.
6. Opening the message box shows the last 3 exchanges above the input, so the thread is one click away. Nothing else stays on screen.
7. `spill message text` sends the same message from the terminal.

## Out of scope
- Attaching a message to a card (comments already do that).
- Rich text or file attachments.

## Acceptance checks
- Click the button, type, Enter: `spill_inbox` shows the message; the bar is back to normal.
- `/` opens it; Esc closes it.
- `spill_reply` shows the reply under the bar, the dot clears once it has been seen.
- A live board change while typing keeps the text.
