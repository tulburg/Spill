S-32 makes "Ask for a change" the main action in a done spec's sheet, so the full-width Revert button steps back. My pick is A: still one click away, but no longer competing with the comment.
- A. A small text link under the comment box: "Revert to discussing".
- B. In a "..." menu in the sheet header, next to Esc.
- C. Removed for done specs; ask for a change instead.
