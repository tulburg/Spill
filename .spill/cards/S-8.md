## Purpose
All messages from the user to Claude go through one textbox at the bottom center of the canvas.

## Requirements
1. A textbox is docked bottom center. Enter sends; Shift+Enter adds a line.
2. A message can be pinned to a card: selecting a card before typing attaches it ("on S-3"), shown as a chip in the textbox that can be removed.
3. Sent messages stack on top of each other above the textbox like a deck: the latest message is fully visible, and only the top edge of each earlier message shows behind it (up to 3 edges). Each message shows its card chip and a delivery state (sent, seen by Claude, answered). Clicking the deck fans it out into a scrollable list.
4. Clicking the canvas collapses the stack into the textbox, which shows a badge with the number of messages ("3").
5. Focusing the textbox expands the stack again.
6. While Claude is building, the collapsed composer shows "Claude building S-n" with a pulse, so the user always sees Claude's state in one place.
7. When a question is waiting, the question popup takes over this slot (D-1); the composer returns once it is answered or set aside.
8. Messages reach Claude through `spill_inbox` as comments on the attached card (or on the project when no card is attached).

## Out of scope
- Rich text, attachments, voice.

## Acceptance checks
- Send three messages: they stack. Click the canvas: stack collapses to a badge "3". Click the textbox: stack expands.
- A message sent with S-3 selected appears in `spill_inbox` as a comment on S-3.
