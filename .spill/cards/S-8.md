## Purpose
Talking to Claude is one button in the bottom-right corner. You type, send, and get back to the board: whatever Claude does shows up on the board itself, so there is no chat panel or thread to watch. Replaces the top bar message button (S-23). Claude only for now.

## Requirements
1. A round button (FAB) sits in the canvas's bottom-right corner. The message button at the right end of the top bar (S-23) is removed; `/` opens the message box too.
2. Clicking the FAB transforms it in place into a message box (it grows out of the button, anchored bottom right). Esc or clicking away with nothing typed shrinks it back; a typed draft survives.
3. Message box: multi-line text, Enter sends, Shift+Enter adds a line. No model name anywhere; Claude is just "Claude".
4. Attachments: an attach button, drag and drop onto the box, and paste. Images show as small thumbnails in the box; other files as a chip with the name. Each can be removed before sending.
5. Attachments are saved under `.spill/attachments/` and listed with the message, so Claude gets file paths it can read.
6. Sending shrinks the box back into the FAB, which then shows a working indicator (a ring around the button): first "received" when the message is logged, then "working" once Claude has read it in `spill_inbox`. It clears when Claude replies or after Claude's next board change.
7. No panel and no thread. Claude's replies show as a popup near the FAB, like today's reply drop (S-23), for 8 seconds.
8. A reply you missed (popup timed out or the window was in the background) leaves a badge with a count on the FAB. Clicking the FAB shows the missed replies above the box, then clears the badge.
9. Claude side: messages arrive in `spill_inbox` (action "message", with attachment paths). `spill_reply` answers as the popup.
10. `spill message text [--file path]` sends the same message from the terminal.

## Out of scope
- A chat panel or message history view.
- Other agents or models.
- Voice, rich text, editing or deleting sent messages.

## Acceptance checks
- The top bar has no message button; the FAB turns into the box and back; the draft survives.
- Send a message with a pasted screenshot: the file is under `.spill/attachments/` and `spill_inbox` lists its path; the FAB shows received, then working after the inbox call.
- A reply shows as a popup; with the window in the background it leaves a badge on the FAB instead.
- No model name appears anywhere.
